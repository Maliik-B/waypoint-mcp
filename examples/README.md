All examples use the same student (Jasmine Bailey, 7th grade, Health Impairment) and lesson ("What is Community?" by Toby Lowe, 45 min ELA).

To regenerate any example:
```bash
npm run build
node -e "const { toolName } = require('./dist/tools/file.js'); console.log(toolName(params));"
```

Or run `npm run demo` to see 6 tools produce output in real time.
